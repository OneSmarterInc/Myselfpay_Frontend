# Country calling codes

Derived from Google libphonenumber PhoneNumberMetadata.xml, downloaded 2026-11-03:
https://github.com/google/libphonenumber/blob/master/resources/PhoneNumberMetadata.xml

Copyright (C) 2009 The Libphonenumber Authors. Licensed under Apache License 2.0; license included in public/licenses/libphonenumber-LICENSE.txt. Only territory identifiers and country calling codes are included. This is a country selection list, not complete phone-number validation metadata. Labels use the browser's English region names. Numbers are verified by the existing Twilio Verify backend. No user data is sent when loading the static list.
